Verifique minha agenda e disponibilidade:

1. Use o MCP do Google Calendar para listar eventos dos próximos 3 dias
2. Identifique horários livres usando a função de find_my_free_time
3. Identifique conflitos de horário se houver
4. Sugira os melhores horários para agendar novas reuniões

Formato:
```
## Agenda - Próximos 3 Dias

### [Data]
- HH:MM-HH:MM - Evento
- HH:MM-HH:MM - LIVRE

### Conflitos Detectados
- (nenhum) ou detalhes

### Melhores Horários para Reuniões
- [Data] HH:MM-HH:MM (X horas livres)
```
