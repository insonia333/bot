Faça um resumo dos meus emails recentes:

1. Use o MCP do Gmail para buscar os emails mais recentes (últimos 3 dias)
2. Agrupe por categoria (trabalho, pessoal, newsletters, notificações)
3. Destaque emails que precisam de resposta urgente
4. Para cada email importante, sugira uma resposta curta

Formato:
```
## Resumo de Emails

### Precisam de Resposta
- [Remetente] Assunto - Sugestão de resposta: "..."

### Informativos
- [Remetente] Assunto - Resumo em 1 linha

### Newsletters/Automáticos
- X newsletters, Y notificações (ignoráveis)
```
