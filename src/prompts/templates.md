# Templates de Prompts

## Template: Resumo de Reunião
```
Resuma a reunião com base nas seguintes notas:
- Participantes: [lista]
- Tópicos discutidos: [lista]
- Decisões tomadas: [lista]
- Próximos passos: [lista]

Gere um resumo formatado e crie um evento de follow-up se necessário.
```

## Template: Resposta Rápida de Email
```
Contexto do email original: [cole aqui]
Tom desejado: [formal/informal/profissional]
Pontos a abordar: [lista]

Gere uma resposta concisa (máx 3 parágrafos).
```

## Template: Planejamento Semanal
```
Com base na minha agenda da semana (use Google Calendar):
1. Liste todos os compromissos
2. Identifique blocos de tempo livre > 1h
3. Sugira como organizar tarefas pendentes nos horários livres
4. Destaque possíveis conflitos
```
