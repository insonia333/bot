Faça um briefing diário completo para mim:

1. **Agenda de Hoje**: Use o MCP do Google Calendar para listar todos os eventos de hoje. Mostre horário, título e localização.

2. **Emails Importantes**: Use o MCP do Gmail para buscar emails não lidos ou recentes (últimas 24h). Destaque os que parecem urgentes ou importantes.

3. **Resumo Executivo**: Faça um resumo curto do dia - quantos compromissos, emails pendentes, e sugestões de prioridade.

Formato de saída:
```
## Briefing Diário - [data]

### Agenda
- HH:MM - Evento (local)

### Emails Prioritários
- De: remetente | Assunto: título | Status: lido/não-lido

### Resumo
- X compromissos hoje
- Y emails para responder
- Sugestão de foco: ...
```
